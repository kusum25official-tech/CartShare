# CartShare – Collaborative Group Shopping

## Project Overview

CartShare is a collaborative shopping web application that allows multiple users to manage a shared shopping cart using a unique room code.

Users can create or join a room, add shopping items, view the shared cart, track activities, and generate a printable receipt.

---

## Problem Statement

Group shopping can become difficult when multiple people need to coordinate items, quantities, prices, and expenses.

CartShare provides a simple shared environment where users can coordinate their shopping through a common room and shared cart.

---

## Key Features

- Create a unique shopping room
- Join an existing room using a room code
- Add shopping items
- Specify quantity and price
- View shared cart items
- Remove items from the cart
- Automatic total calculation
- Activity log
- Browser-based data persistence
- Synchronization across browser tabs
- Printable shopping receipt
- Responsive user interface
- Mobile-friendly design
